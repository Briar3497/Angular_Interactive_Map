🗺️ Angular Interactive Map Project

A high-performance, interactive mapping application built with Angular. This project enables users to visualize geospatial data through dynamic layers, custom markers, and real-time interaction.

🚀 Quick Start

git clone https://github.com/Briar3497/Angular_Interactive_Map.git

code "Angular_Interactive_Map"

ng serve -o

If not already install, this app will require angular and/or npm

🛠️ Built With

• Angular

• Angular CLI
